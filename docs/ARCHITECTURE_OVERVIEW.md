# 架构总览（初始版）

当前仓库处于冷启动阶段，先以“可扩展骨架”为目标。

## 分层建议

- **入口层（未来）**：CLI / HTTP API / Worker
- **应用层**：业务用例编排
- **领域层**：核心业务规则
- **基础设施层**：数据库、缓存、第三方服务

## 目录映射建议

- `src/app/`：应用层
- `src/domain/`：领域层
- `src/infra/`：基础设施层
- `src/interfaces/`：入口/接口适配层

## 演进原则

1. 先实现最小可运行路径（MVP）
2. 每次仅做一个可回滚的小改动
3. 功能与测试同时提交
4. 文档与代码同步更新
